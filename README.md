# Training Hub

App personal për Android që ndjek programin Shortcut to Size të Jim Stoppani dhe programe të tjera, peshat, matjet e trupit, ushqimin dhe suplementet. Funksionon pa internet dhe sinkronizon me Supabase.

- Specifikimi: [`docs/SPEC.md`](docs/SPEC.md)
- Detyrat: [`docs/TICKETS.md`](docs/TICKETS.md)
- Dizajni: [`DESIGN.md`](DESIGN.md) (Omal UI v2)

## Nisja

```bash
npm install
npm run dev     # serveri lokal
npm test        # testet
npm run lint    # oxlint + rregullat e dizajnit
npm run build   # build
```
